# Система Управління Гуртожитком (Dormitory Admin Dashboard)
Комплексна вебсистема для автоматизації та управління процесами
студентського гуртожитку. Проєкт розроблено для спрощення роботи
адміністрації (коменданта) та забезпечення зручного доступу мешканців до
власної інформації.
Система поєднує інструменти для управління житловим фондом, фінансового
обліку, обробки заявок та ведення реєстру документів.
---
## 🛠 Технологічний стек
* **Фреймворк:** [Next.js 14+](https://nextjs.org/) (App Router, Server
  Components, Server Actions)
* **Мова програмування:** [TypeScript](https://www.typescriptlang.org/)
  (Strict Mode)
* **База даних:** [PostgreSQL](https://www.postgresql.org/)
* **ORM:** [Prisma Client](https://www.prisma.io/)
* **Автентифікація:** [NextAuth.js](https://next-auth.js.org/) (Role-Based
  Access Control)
* **UI та Стилізація:** [Tailwind CSS](https://tailwindcss.com/),
  компоненти [shadcn/ui](https://ui.shadcn.com/)
* **Візуалізація даних:** [Recharts](https://recharts.org/)
* **Тестування:** [Jest](https://jestjs.io/), React Testing Library
* **CI/CD:** GitHub Actions

## Основний функціонал
### 1. Система авторизації та керування ролями (RBAC)
* Розподіл прав доступу між двома основними ролями: **Адміністратор
  (Комендант)** та **Мешканець (Студент)**.
* Безпечне керування сесіями та захист маршрутів на рівні Middleware.
### 2. Управління житловим фондом
* Інтерактивні картки кімнат із відображенням загальної місткості та
  кількості вільних місць.

* Механізм поселення та виселення студентів зі зміною статусу кімнати в
  реальному часі.
* Можливість переведення окремих кімнат у статус ремонту.
### 3. Особистий профіль мешканця
* Облік персональних даних, академічної групи, контактної інформації.
* **Історія поселень:** відстеження поточного та архівних місць проживання.
* **Фінансовий модуль:** Перегляд історії нарахувань, статусу оплат та
  можливість імітації погашення заборгованості.
* **Електронний реєстр документів:** Чек-лист для обліку наявності
  документів (паспорт, медична довідка, договір).
* **Безпека даних:** Каскадне видалення зв'язаних даних при видаленні
  профілю.
### 4. Система заявок (Helpdesk / Kanban Board)
* Інтерактивна дошка для обробки скарг та заявок на технічне
  обслуговування.
* Можливість подання анонімних звернень.
### 5. Аналітична панель (Dashboard)
* Агрегація даних через паралельні запити (`Promise.all`) для високої
  швидкості.
* Візуалізація зайнятості фонду за допомогою кільцевої діаграми.
* Інструмент для **масового автоматичного нарахування плати** за
  проживання.

## Встановлення та запуск
1. **Клонування репозиторію:**
```bash
git clone <url_репозиторію>
cd dormitory-admin
```
2. **Встановлення залежностей:**
```bash
npm install
```
3. **Налаштування середовища:**
   Створіть файл `.env` у корені проєкту:

```env
DATABASE_URL="postgresql://user:password@localhost:5432/dormitory?
schema=public"
NEXTAUTH_SECRET="ваш_секретний_ключ"
NEXTAUTH_URL="http://localhost:3000"
```
4. **Ініціалізація бази даних:**
```bash
npx prisma generate
npx prisma db push
```
5. **Запуск сервера розробки:**
```bash
npm run dev
```
